# Analyze this code for performance issues and suggest optimizations

Examine the selected code or current file for performance issues and provide concrete optimization suggestions.

## Analysis areas
- Time complexity (algorithmic inefficiency)
- Space complexity (unnecessary allocations)
- Database queries (N+1, missing indexes, inefficient queries)
- Memory leaks and resource management
- Hot path inefficiencies
- Redundant computations

## Output format
1. **Issues found** — list of performance problems with severity (critical/high/medium/low)
2. **Root cause** — why each issue matters
3. **Optimization** — concrete code change with example
4. **Impact** — expected improvement (latency/memory/throughput)
